# 🏋️ FitLog — Workout Library

**Train with Intent. Log Every Set.**

FitLog is a modern, dark-themed workout library and gym companion built with Next.js. It allows users to explore different exercises, view detailed workout instructions, create a daily workout plan, and save their favorite exercises for later.

The application provides a simple and organized way to manage workouts, track daily exercise statistics, and stay consistent with fitness goals.

---

## ✨ Features

### 1. 🏠 Workout Library

- Browse a collection of 12 different workouts.
- Responsive 3-column/4-row workout grid on large screens.
- Workout cards display images, categories, equipment, duration, calories, and ratings.
- Click any workout to view its detailed information.
- Loading animation while workout data is being fetched.

### 2. 💪 Workout Details

- Detailed workout information with a two-column layout.
- Large workout illustrations.
- Muscle group and category tags.
- Equipment, difficulty, sets, reps, duration, calories, and rating.
- Step-by-step workout instructions.
- Add workouts to Today's Plan.
- Save favorite workouts for later.
- Toast notifications for user actions.

### 3. 📋 My Plan

- Manage Today's Plan and Saved workouts separately.
- Daily workout statistics:
  - Total Exercises
  - Total Minutes
  - Total Calories
- Maximum of five workouts in Today's Plan.
- Mark workouts as completed.
- Remove workouts from the plan.
- Unsave previously saved workouts.
- View Details button for each workout.
- Empty state when no workouts are available.

### 4. 🔍 Sorting & Navigation

- Sort workouts by Duration, Calories, and Rating.
- Responsive navigation bar.
- Active navigation link highlighting.
- Dynamic Plan and Saved counters.
- Easy navigation between the workout library and My Plan.

### 5. 🎨 Responsive UI & User Experience

- Modern dark-themed interface.
- Lime-green accent color.
- Responsive layouts for desktop, tablet, and mobile.
- Interactive buttons and hover effects.
- Toast notifications for important actions.
- Custom 404 page for invalid routes.

## 📱 Responsive Design

FitLog is designed to work across different screen sizes.

- **Desktop:** Full navigation, spacious workout cards, and multi-column layouts.
- **Tablet:** Adaptive grid and optimized spacing.
- **Mobile:** Stacked layouts, compact workout cards, and mobile-friendly navigation.

## 🎯 Project Objectives

The main objective of FitLog is to provide an organized workout management experience through a clean interface and practical functionality.

This project demonstrates the use of modern frontend technologies, reusable React components, dynamic routing, state management, responsive design, and interactive user experiences.
